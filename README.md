## Importer sur GitHub Pages sans casser le site

1. Décompressez le ZIP de cette version.
2. Ouvrez https://github.com/ajyamary/ajyamary.github.io puis `Add file → Upload files`.
3. Déposez les fichiers `index.html`, `styles.css`, `script.js`, `README.md` à la racine, ainsi que les dossiers **`assets`** (y compris `favicon.svg`) et **`cv`** en conservant les dossiers. Déposez aussi `contact.vcf`.
4. Confirmez l’écrasement des fichiers existants en soumettant `Commit changes`.
5. Vérifiez la publication sur https://ajyamary.github.io/ : parfois un rechargement forcé `Ctrl+F5` est nécessaire.
6. Vérifiez sur smartphone : bouton d’appel, WhatsApp, téléchargements des deux CV et ajout au contact.

**Important :** gardez les deux fichiers PDF dans `cv/`. Les liens `/cv/CV_ESMEL_AMARY_Data_IA.pdf` et `/cv/CV_ESMEL_AMARY_Consultant_Formateur.pdf` sont relatifs à la racine du site.
